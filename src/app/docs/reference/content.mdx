# Word reference

Complete FORTH vocabulary and Bitcoin Script opcodes for Henceforth.

<a id="reference" />

## Reference

Everything in FORTH is a **word** separated by spaces. That's all there is to the syntax. It's so simple.

> **FORTH is LIFO** — FORTH is a stack-based programming language which operates on a *Last In, First Out* principle.

<a id="ref-compile" />

### Compile Words

One of the great things about FORTH is its ability to extend the compiler during run time.

<Word name=":">Puts the user into compile mode where they can start to define their own word.</Word>

<Word name=";">Exits compile mode so that word interpretation can again occur.</Word>

<Word name="recurse">Calls the word being executed.</Word>

<Word name="exit">Exits the current word.</Word>

<Word name="immediate">Marks the most recently defined word as immediate, causing it to execute during compilation rather than being compiled.</Word>

<Word name="postpone">Forces compilation of the next word, even if it is marked IMMEDIATE. Used inside definitions to defer execution of immediate words.</Word>

<Word name="value" stack="(x --)">Creates a named value that can be read by name and changed with TO. Usage: `42 value myval`.</Word>

<Word name="to" stack="(x --)">Change the value of a word created with VALUE. Usage: `99 to myval`.</Word>

<Word name="does>" stack="( -- )">Defines the runtime behaviour of a CREATE'd word. Everything after DOES> runs when the created word is executed, with the data-field address on the stack. Usage: `: array create cells allot does> swap cells + ;`.</Word>

<Word name="include" stack="( -- )">Loads and runs a FORTH file. Usage: `include maths.fs`.</Word>

<a id="ref-meta" />

### Meta Programming

<Word name="'" stack="( -- xt)">Gets the execution token of the named word. Used to get a reference to a word for later execution.</Word>

<Word name="[']" stack="( -- xt)">Compile-time version of `'` (tick). Compiles the execution token of a word into the current definition.</Word>

<Word name="execute" stack="(i*x xt -- j*x)">Executes the word whose execution token is on the stack. The `i*x`/`j*x` notation acknowledges that the executed word may consume and produce arbitrary values; only the xt itself is consumed by EXECUTE.</Word>

<Word name="literal" stack="Compile: (x -- )  Run-time: ( -- x)">At compile time, compiles a numeric literal into the current definition; at run time of the containing word, pushes that literal onto the stack. Used inside IMMEDIATE words to inject computed constants into the word being defined.</Word>

<Word name="state" stack="( -- addr)">Returns the address of the STATE variable. STATE is 0 when interpreting, -1 when compiling.</Word>

<Word name="[" stack="(--)">Switches from compilation mode to interpretation mode.</Word>

<Word name="]" stack="(--)">Switches from interpretation mode to compilation mode.</Word>

<Word name="evaluate" stack="(c-addr u --)">Interprets the string at c-addr of length u as if it were typed at the terminal.</Word>

<Word name="find" stack="(c-addr -- c-addr 0 | xt 1 | xt -1)">Searches the dictionary for the counted string at c-addr. Returns xt and 1 (immediate) or -1 (normal), or c-addr and 0 if not found.</Word>

<Word name=">body" stack="(xt -- a-addr)">Returns the data-field address of a CREATE'd word given its execution token.</Word>

<Word name=">in" stack="( -- a-addr)">Returns the address of the variable holding the current input parse position.</Word>

<Word name=">number" stack="(ud1 c-addr1 u1 -- ud2 c-addr2 u2)">Converts characters at c-addr to a number using the current BASE. Stops at the first non-convertible character.</Word>

<a id="ref-arithmetic" />

### Arithmetic

Arithmetic is done using reverse Polish notation, so the numbers are required on the stack before the arithmetic operator can be used.

<Word name="+" stack="(n1 n2 -- sum)">Takes the top two items from the stack and returns their sum.</Word>

<Word name="-" stack="(n1 n2 -- difference)">Takes the top two items from the stack and returns their difference.</Word>

<Word name="*" stack="(n1 n2 -- product)">Takes the top two items from the stack and returns their product.</Word>

<Word name="/" stack="(n1 n2 -- quotient)">Takes the top two items from the stack and returns their quotient.</Word>

<Word name="*/" stack="(n1 n2 n3 -- result)">`result = (n1*n2/n3)`. Multiplies n1 by n2, then divides by n3.</Word>

<Word name="mod" stack="(n1 n2 -- modulus)">Divides the first by the second; the remainder is added to the stack.</Word>

<Word name="/mod" stack="(n1 n2 -- modulus quotient)">Returns the modulus and the quotient.</Word>

<Word name="abs" stack="(n -- |n|)">Absolute value of the top item on the stack.</Word>

<Word name="negate" stack="(n -- -n)">Negates the top item.</Word>

<Word name="max" stack="(n1 n2 -- max)">Returns the greater of two values.</Word>

<Word name="min" stack="(n1 n2 -- min)">Returns the smaller of two values.</Word>

<Word name="1+" stack="(n -- n+1)">Increments the top item.</Word>

<Word name="1-" stack="(n -- n-1)">Decrements the top item.</Word>

<Word name="2+" stack="(n -- n+2)" ext>Adds 2 to the top of the stack. Henceforth extension — equivalent to `2 +`.</Word>

<Word name="2-" stack="(n -- n-2)" ext>Subtracts 2 from the top of the stack. Henceforth extension.</Word>

<Word name="2*" stack="(n -- n*2)">Doubles the top item.</Word>

<Word name="2/" stack="(n -- n/2)">Halves the top item.</Word>

<Word name="sumStack" stack="(n1 ... n -- sum)" ext>Sums every value on the stack into a single result. Henceforth extension — not in Forth-2012.</Word>

<Word name="*/mod" stack="(n1 n2 n3 -- remainder quotient)">Multiplies n1 by n2, then divides by n3. Returns both the remainder and the quotient.</Word>

<a id="ref-double-cell" />

### Double-Cell Arithmetic

Double-cell words operate on 64-bit values represented as two stack items (high cell on top). These are required by the Forth-2012 CORE standard for intermediate precision in calculations.

<Word name="s>d" stack="(n -- d)">Sign-extends a single-cell number to a double-cell number. Required before FM/MOD or SM/REM.</Word>

<Word name="m*" stack="(n1 n2 -- d)">Signed multiply of n1 by n2, producing a double-cell result. No overflow possible.</Word>

<Word name="um*" stack="(u1 u2 -- ud)">Unsigned multiply of u1 by u2, producing an unsigned double-cell result.</Word>

<Word name="fm/mod" stack="(d n1 -- n2 n3)">Floored division of double-cell d by n1. The quotient n3 rounds toward negative infinity. The remainder n2 has the same sign as the divisor.</Word>

<Word name="sm/rem" stack="(d n1 -- n2 n3)">Symmetric division of double-cell d by n1. The quotient n3 rounds toward zero. The remainder n2 has the same sign as the dividend.</Word>

<Word name="um/mod" stack="(ud u1 -- u2 u3)">Unsigned division of unsigned double-cell ud by u1. Returns remainder u2 and quotient u3.</Word>

<a id="ref-numeric-output" />

### Numeric Output

<Word name="<#" stack="(--)">Initialises pictured numeric output conversion.</Word>

<Word name="#" stack="(ud1 -- ud2)">Converts one digit from the double number and adds it to the pictured numeric output buffer.</Word>

<Word name="#s" stack="(ud -- 0 0)">Converts all remaining digits from the double number until it becomes zero.</Word>

<Word name="#>" stack="(xd -- c-addr u)">Completes pictured numeric conversion and returns the address and length of the formatted string.</Word>

<Word name="hold" stack="(char --)">Adds a character to the beginning of the pictured numeric output buffer.</Word>

<Word name="sign" stack="(n --)">If the number is negative, adds a minus sign to the pictured numeric output.</Word>

<Word name=".r" stack="(n1 n2 --)">Displays a number right-aligned in a field of n2 characters width.</Word>

<Word name="u." stack="(u --)">Displays an unsigned number followed by a space.</Word>

<Word name="u.r" stack="(u n --)">Displays an unsigned number right-aligned in a field of n characters width.</Word>

<a id="ref-comparison" />

### Comparison

> `f` is a flag or bool `[true | false]`. Per Forth-2012, `TRUE` is `-1` (all bits set) and `FALSE` is `0`. Any non-zero value is considered true by `IF`, `AND`, `OR`, and other conditional words.

<Word name="=" stack="(n1 n2 -- f)">Returns the flag for n1 equal to n2.</Word>

<Word name="<>" stack="(n1 n2 -- f)">Returns the flag for n1 not equal to n2.</Word>

<Word name="<" stack="(n1 n2 -- f)">True if n1 is less than n2.</Word>

<Word name=">" stack="(n1 n2 -- f)">True if n1 is greater than n2.</Word>

<Word name="&&" stack="(n1 n2 -- f)" ext>Logical AND — Henceforth extension. Returns -1 if both values are non-zero, 0 otherwise.</Word>

<Word name="||" stack="(n1 n2 -- f)" ext>Logical OR — Henceforth extension. Returns -1 if either value is non-zero, 0 otherwise.</Word>

<Word name="0=" stack="(n -- f)">True if n is zero.</Word>

<Word name="0<" stack="(n -- f)">True if n is less than zero.</Word>

<Word name="0>" stack="(n -- f)">True if n is greater than zero.</Word>

<Word name="u<" stack="(u1 u2 -- f)">Unsigned comparison. True if u1 is less than u2 when both are treated as unsigned.</Word>

<a id="ref-bitwise" />

### Bitwise

<Word name="and" stack="(x1 x2 -- x3)">Bitwise AND of the top two values (Forth-2012 6.1.0720). When both operands are well-formed flags (0 or -1), bitwise AND produces logical AND — so you don't need a separate logical operator if you keep flags well-formed.</Word>

<Word name="or" stack="(x1 x2 -- x3)">Bitwise OR of the top two values (Forth-2012 6.1.1980).</Word>

<Word name="xor" stack="(x1 x2 -- x3)">Bitwise XOR of the top two values (Forth-2012 6.1.2490).</Word>

<Word name="invert" stack="(n -- ~n)">Bitwise inversion. Flips every bit of the top value on the stack.</Word>

<Word name="rshift" stack="(n1 n2 -- n3)">Returns n1 bitwise right-shifted by n2.</Word>

<Word name="lshift" stack="(n1 n2 -- n3)">Returns n1 bitwise left-shifted by n2.</Word>

<a id="ref-stack" />

### Stack Operators

<Word name=".s" stack="( -- )">Displays the current stack to the terminal.</Word>

<Word name="." stack="(n -- )">Pops the top value to the terminal.</Word>

<Word name="dup" stack="(n -- n n)">The top value is duplicated and both the original and copy are returned.</Word>

<Word name="?dup" stack="(n -- 0 | n n)">Duplicates the top item only if it is non-zero.</Word>

<Word name="nip" stack="(n1 n2 -- n2)">Drops the first item below the top of the stack.</Word>

<Word name="swap" stack="(n1 n2 -- n2 n1)">Swaps the top two values.</Word>

<Word name="drop" stack="(n -- )">Discards the top item.</Word>

<Word name="2dup" stack="(n1 n2 -- n1 n2 n1 n2)">Duplicates the top two values.</Word>

<Word name="over" stack="(n1 n2 -- n1 n2 n1)">Copies the second value and pushes it on top.</Word>

<Word name="pick" stack="(x_u ... x_1 x_0 u -- x_u ... x_1 x_0 x_u)">Pops u and pushes a copy of the u-th item from the stack (0-indexed from top: `0 PICK` is DUP, `1 PICK` is OVER).</Word>

<Word name="rot" stack="(n1 n2 n3 -- n2 n3 n1)">Rotates the top three values left.</Word>

<Word name="-rot" stack="(n1 n2 n3 -- n3 n1 n2)">Rotates the top three values right.</Word>

<Word name="tuck" stack="(n1 n2 -- n2 n1 n2)">Copies the top value and places it before the second value (third deep).</Word>

<Word name="2drop" stack="(n1 n2 -- )">Discards the top two values.</Word>

<Word name="2swap" stack="(n1 n2 n3 n4 -- n3 n4 n1 n2)">Reverses the order of the top two pairs.</Word>

<Word name="2over" stack="(n1 n2 n3 n4 -- n1 n2 n3 n4 n1 n2)">Copies items 3 and 4 deep onto the top.</Word>

<Word name="reverseStack" stack="(n1 n2 ... nlast -- nlast ... n2 n1)" ext>Reverses the order of every item on the stack. Henceforth extension — not in Forth-2012.</Word>

<Word name="depth" stack="( -- n)">Returns the number of items currently on the data stack before DEPTH was executed.</Word>

<Word name="roll" stack="(xu xu-1 ... x0 u -- xu-1 ... x0 xu)">Rotates u+1 items on the stack. The u-th item is moved to the top.</Word>

<Word name="stackCount" stack="( -- n)">Pushes the number of items currently on the stack. Novice-friendly Henceforth alias for `depth` (Forth-2012 6.1.1200).</Word>

<a id="ref-return-stack" />

### Return Stack

<Word name=">r" stack="(x -- )  ( R: -- x)">Pops the parameter stack and pushes onto the return stack.</Word>

<Word name="r>" stack="( -- x)  ( R: x -- )">Pops the return stack and pushes onto the parameter stack.</Word>

<Word name="r@" stack="( -- x)  ( R: x -- x)">Copies the top of the return stack to the parameter stack.</Word>

<Word name="i" stack="( -- x)">The innermost DO LOOP's index. Copies the top of the return stack.</Word>

<Word name="i'" stack="( -- x)">The next-outer loop's index in nested DO LOOPs. Copies the second-from-top of the return stack. In Henceforth `i'` and `j` return the same value.</Word>

<Word name="j" stack="( -- x)">The next-outer loop's index in nested DO LOOPs (Forth-2012 6.1.1730).</Word>

<Word name="nth" stack="(u -- x)" ext>Pops u and pushes the u-th item from the return stack (0-indexed from top). Henceforth extension.</Word>

<a id="ref-decision" />

### Decision

> `f` is a flag or bool `[true | false]`.

<Word name="if" stack="(x -- )">Pops one cell. If non-zero, executes the words up to ELSE or THEN. If zero, skips over them.</Word>

<Word name="else" stack="( -- )">The optional false branch of an IF...THEN. No runtime stack effect — the flag was already consumed by IF.</Word>

<Word name="then" stack="( -- )">Denotes the end of the IF...THEN statement. No runtime stack effect.</Word>

<Word name="not" stack="(x -- f)">Synonym for `0=` (returns -1 if x is 0, 0 otherwise). Retained for FIG-FORTH compatibility. Forth-2012 dropped `NOT` because pre-2012 implementations disagreed on whether it meant `0=` (logical) or `INVERT` (bitwise). Henceforth's `NOT` is the logical version. Prefer `0=` or `INVERT` in new code.</Word>

<Word name="within" stack="(n1 n2 n3 -- f)">True if n2 is between n1 and n3.</Word>

<Word name="true" stack="( -- -1)">Pushes the true flag (-1, all bits set). Per Forth-2012 standard.</Word>

<Word name="false" stack="( -- 0)">Pushes the false flag (0).</Word>

<Word name="case" stack="( -- )">Begins a CASE...OF...ENDOF...ENDCASE switch statement. The selector value must be on the stack.</Word>

<Word name="of" stack="(x1 x2 -- | x1)">Compares the top of stack with the selector. If equal, drops both and executes the clause. If not, skips to ENDOF.</Word>

<Word name="endof" stack="( -- )">Ends an OF clause. Branches to after ENDCASE.</Word>

<Word name="endcase" stack="(x -- )">Ends a CASE statement. Drops the selector value if no OF clause matched.</Word>

<Word name="catch" stack="(i*x xt -- j*x 0 | i*x n)">Executes the word referred to by xt while protecting the data stack. Returns 0 on success. If THROW is called during execution, restores the stack to its pre-CATCH depth and returns the thrown error code n.</Word>

<Word name="throw" stack="(k*x n -- k*x | i*x n)">If n is 0, does nothing. Otherwise unwinds the stack to the nearest CATCH, leaving n as the result. The exception code is implementation-defined; -1 is conventional for ABORT, -2 for ABORT".</Word>

<a id="ref-loop" />

### Loop

<Word name="do" stack="(n1 n2 --)">n1 is endValue, n2 is startValue. Repeats words between DO and LOOP from startValue until endValue is met.</Word>

<Word name="loop" stack="( -- )">Ends loop.</Word>

<Word name="+loop" stack="(n1 -- )">Loops in n1 increments.</Word>

<Word name="every" stack="(n1 -- )">Performs the following word every n1 seconds until STOP is called. Henceforth scheduling extension.</Word>

<Word name="stop" stack="( -- )" ext>Stops the EVERY loop. Henceforth extension — pairs with EVERY only.</Word>

<Word name="begin" stack="( -- )">Marks the start of a BEGIN...UNTIL or BEGIN...WHILE...REPEAT loop.</Word>

<Word name="while" stack="(x -- )">Tests a condition within a BEGIN...REPEAT loop. Pops one cell; if zero, exits the loop.</Word>

<Word name="repeat" stack="( -- )">Marks the end of a BEGIN...WHILE...REPEAT loop and jumps back to BEGIN.</Word>

<Word name="until" stack="(x -- )">Pops one cell; if zero, jumps back to BEGIN. If non-zero, falls through.</Word>

<Word name="leave" stack="( -- )">Exits the current DO...LOOP or DO...+LOOP immediately. Must be used within a loop.</Word>

<Word name="unloop" stack="( -- )">Discards the loop control parameters from the return stack. Used when exiting a loop early with LEAVE.</Word>

<Word name="?do" stack="(n1 n2 --)">Like DO but skips the loop entirely if the start and end values are equal. Executes loop from n1 to n2-1.</Word>

<Word name="again" stack="( -- )">Unconditional branch back to BEGIN. Creates an infinite loop (BEGIN...AGAIN). Use LEAVE or the Escape key to exit.</Word>

<a id="ref-base" />

### Base

Henceforth accepts integers as binary, octal, decimal and hexadecimal. Just change the base.

<Word name="base" stack="( -- addr)">Returns the address of the BASE variable. Use `BASE @` to read and `n BASE !` to write. Supports bases 2 through 36.</Word>

<Word name="decimal" stack="(--)">Sets BASE to 10. Forth-2012 6.1.1170.</Word>

<Word name="binary" stack="(--)" ext>Sets BASE to 2. Henceforth extension. Equivalent to `2 BASE !`.</Word>

<Word name="octal" stack="(--)" ext>Sets BASE to 8. Henceforth extension. Equivalent to `8 BASE !`.</Word>

<Word name="hex" stack="(--)">Sets BASE to 16. Forth-2012 6.2.1660.</Word>

### Pop-up

<Word name="lineChart" stack="(--)">Displays a line chart representing the stack.</Word>

<Word name="barChart" stack="(--)">Displays a bar chart representing the stack.</Word>

<Word name="pieChart" stack="(--)">Displays a pie chart representing the stack with slices in proportion to each value's weight compared to the sum.</Word>

<a id="ref-constants" />

### Constants & Variables

<Word name="constant" stack="(n --)">Takes a value from the stack and a name; creates a constant of that value called by the name provided.</Word>

<Word name="variable" stack="(--)">Creates a variable whose name will be the first string of characters following VARIABLE, initially zero.</Word>

<Word name="!" stack="(n address --)">Stores a number to the address provided.</Word>

<Word name="@" stack="(address -- n)">Gives the value from address.</Word>

<Word name="?" stack="(address --)">Prints the value from address to the terminal.</Word>

<Word name="c!" stack="(char addr --)">Stores a single character at the specified memory address.</Word>

<Word name="c@" stack="(addr -- char)">Fetches a single character from the specified memory address and places it on the stack.</Word>

<Word name="create" stack="(--)">Creates an array named by the first string of characters following CREATE.</Word>

<Word name="," stack="(n --)">Stores the top value as part of the array in the current data-space position.</Word>

<Word name="allot" stack="(n --)">Allocates n cells of data space. Used after CREATE to allocate memory for arrays or data structures.</Word>

<Word name="here" stack="( -- addr)">Returns the address of the next available data space location.</Word>

<Word name="cells" stack="(n1 -- n2)">Converts a count to an address offset by multiplying by the cell size.</Word>

<Word name="cell+" stack="(addr1 -- addr2)">Adds the size of one cell to an address, advancing it to the next cell boundary.</Word>

<Word name="+!" stack="(n addr --)">Adds n to the value stored at the given address.</Word>

<Word name="count" stack="(c-addr1 -- c-addr2 u)">Converts a counted string (length byte followed by characters) to an address and length suitable for TYPE.</Word>

<Word name="bl" stack="( -- char)">Pushes the ASCII value for space character (32) onto the stack.</Word>

<Word name="2@" stack="(addr -- x1 x2)">Fetches two consecutive cells from memory at the given address.</Word>

<Word name="2!" stack="(x1 x2 addr --)">Stores two consecutive values to memory at the given address.</Word>

<Word name="fill" stack="(addr u char --)">Fills u bytes of memory starting at addr with the specified character value.</Word>

<Word name="move" stack="(addr1 addr2 u --)">Copies u address units from addr1 to addr2. Handles overlapping memory regions correctly.</Word>

<Word name="erase" stack="(addr u --)">Fills u address units with zeros, effectively clearing the memory region.</Word>

<Word name="allocate" stack="(u -- a-addr ior)">Allocates u cells of contiguous data space. Returns the start address and an I/O result code (0 = success, -1 = failure). Reuses previously freed blocks when possible.</Word>

<Word name="free" stack="(a-addr -- ior)">Releases previously allocated memory starting at addr. Returns 0 on success. Adjacent freed blocks are merged to reduce fragmentation.</Word>

<Word name="resize" stack="(a-addr u -- a-addr2 ior)">Changes the size of an allocation. If the new size fits within the existing block, returns the same address. Otherwise allocates a new block, copies existing data, and frees the old block.</Word>

<Word name="c," stack="(char --)">Reserves one character of data space and stores char in it.</Word>

<Word name="char+" stack="(c-addr1 -- c-addr2)">Adds the size of one character to the address.</Word>

<Word name="chars" stack="(n1 -- n2)">Returns the size in address units of n characters. In this system, 1 char = 1 unit.</Word>

<Word name="align" stack="( -- )">Aligns the data-space pointer to a cell boundary.</Word>

<Word name="aligned" stack="(addr -- a-addr)">Returns the first aligned address greater than or equal to addr.</Word>

<a id="ref-terminal" />

### Terminal

<Word name="cr" stack="(--)">Newline added to terminal.</Word>

<Word name="space" stack="(--)">Adds a single space to the terminal.</Word>

<Word name="spaces" stack="(n --)">Adds n spaces to the terminal.</Word>

<Word name="emit" stack="(n --)">Emits the ASCII code on top of the stack.</Word>

<Word name="(" stack="(--)">Starts inline comment. Everything between `(` and `)` will be ignored. Can appear anywhere on a line.</Word>

<Word name=")" stack="(--)">Ends inline comment.</Word>

<Word name="\\" stack="(--)">Line comment. Everything after `\` to the end of the line is ignored. Supported in `.fs` files.</Word>


<Word name=".rs" stack="(--)" ext>Displays the return stack on the terminal. Henceforth extension — Forth-2012 only specifies `.s` for the data stack.</Word>

<Word name="clear" stack="(i*x --)" ext>Empties the data stack, return stack, and terminal screen. Henceforth extension — non-standard. For just the screen use `page`; for stacks alone use `abort`.</Word>

<Word name="bye" stack="(--)">Clears everything, resets to default settings.</Word>

<Word name='."' stack="(--)">Start print. Everything between quotes is printed.</Word>

<Word name='"' stack="(--)">Ends print.</Word>

<Word name='s"' stack="( -- addr u)">Creates a string literal. Returns the address and length of the string on the stack.</Word>

<Word name="type" stack="(addr u --)">Displays the string at that address to the terminal.</Word>

<Word name="page" stack="(--)">Clears the terminal screen (Forth-2012 6.2.2030). In Henceforth's append-only buffer this empties every prior entry so the next emission starts at the top. Does not affect the data, return, or data stack.</Word>

<Word name="ms" stack="(u --)">Wait at least u milliseconds before the next loop iteration (Forth-2012 FACILITY 10.6.2.1905). Use it to pace animation and screen updates.</Word>

<Word name="char" stack="( -- char)">Parses the next space-delimited word and returns the ASCII value of its first character.</Word>

<Word name="[char]" stack="( -- n)">Compile-time version of CHAR. Compiles the character value into the current definition.</Word>

<Word name="word" stack="(char -- c-addr)">Parses the input stream until the delimiter character is found and returns a counted string address.</Word>

<Word name="parse" stack="(char -- c-addr u)">Parses the input stream until the delimiter character is found and returns address and length.</Word>

<Word name="key" stack="( -- n)">Waits for a single keypress and pushes its ASCII value onto the stack. Blocks execution until a key is pressed.</Word>

<Word name="?terminal" stack="( -- flag)">Returns -1 if the keyboard buffer has input or a terminal interrupt has been requested, 0 otherwise. The Forth-2012 standard name is `ekey?` (FACILITY 10.6.2.1306); both spellings dispatch to the same handler.</Word>

<Word name="accept" stack="(c-addr n1 -- n2)">Receives up to n1 characters from the input source and stores them at c-addr. Returns n2, the actual number of characters received.</Word>

<Word name="sessionInput" stack="(--)">Displays session input.</Word>

<Word name="dictionary" stack="(--)" ext>Shows the user's defined words, constants, and variables. Henceforth extension. For all words (built-in plus user-defined) use `words` or `vlist`.</Word>

<Word name="vlist" stack="(--)">Displays a list of every built-in word Henceforth offers. The Forth-2012 standard name is `words` (TOOLS 15.6.1.2465); both spellings dispatch to the same handler.</Word>

<Word name="see" stack='( "<spaces>name" --)'>Shows what a word does: user-defined words print their source; built-in words print their stack diagram and description (TOOLS 15.6.1.2194). Usage: `see pay-rent`.</Word>

<Word name="help" stack='( "<spaces ext>name" --)'>Prints a word's stack diagram and description. Bare `help` opens the vocabulary browser. Henceforth extension.</Word>

<Word name="forth" stack="(--)">Resets vocabulary to standard built-in words, removing all user definitions.</Word>

<Word name='c"' stack="( -- c-addr)">Creates a counted string literal. Returns the address of a counted string (length byte followed by characters).</Word>

<Word name="abort" stack="(--)">Clears all stacks and resets the interpreter state.</Word>

<Word name='abort"' stack="(flag --)">If the flag is non-zero, displays the message and ABORTs. Otherwise discards the message and continues. Usage: `0= abort" value must not be zero"`.</Word>

<Word name="quit" stack="(--)">Clears the return stack and enters interpretation state.</Word>

<Word name="source" stack="( -- c-addr u)">Returns the address and length of the current input buffer.</Word>

<Word name="environment?" stack="(c-addr u -- false | i*x true)">Queries the system for an environmental parameter. Returns false if unknown, or the value and true if known.</Word>

### Other Words

### Data Conversion

Henceforth has three stacks: the integer stack (main, inspected via `.s`), the data stack (raw bytes for Bitcoin Script operations, inspected via `.ds`), and the return stack (Forth-2012 `>R` / `R>` / `R@`, inspected via `.rs`). These words bridge the integer and data stacks.

<Word name="hex>data" stack="( c-addr u -- )">Converts a hex string from the integer stack `(c-addr u)` to bytes on the data stack. Compose with `S"`: `S" deadbeef " hex>data`. Legacy spelling `hex2data` still parses as a silent alias for backwards compatibility with pre-2026-05-19 scripts.</Word>

<Word name="chars>data" stack="( c-addr u -- )">Converts a UTF-8 string from the integer stack `(c-addr u)` to bytes on the data stack. Compose with `S"`: `S" hello " chars>data`. No auto-detect between hex and UTF-8 — silent hex interpretation of a UTF-8-intended OP_RETURN payload would broadcast wrong bytes to chain. Use `hex>data` for hex decoding, `chars>data` for raw UTF-8 bytes.</Word>

<Word name="data>hex" stack="( -- )">Pops the top of the data stack and displays it as a lowercase hex string on the terminal. Legacy spelling `data2hex` still parses as a silent alias for backwards compatibility.</Word>

<Word name=".ds" stack="( -- )">Displays the contents of the data stack.</Word>

<Word name=">data" stack="( -- )">Converts the following token to raw data bytes and pushes them onto the data stack.</Word>

<Word name=">addr" stack="(n -- )">Marks the top-of-stack integer value as a Bitcoin address string for transaction building.</Word>

<Word name=">scriptnum" stack="( n -- )">Moves an integer from the integer stack to the script (data) stack as a minimally-encoded script number. Usage: `5 >scriptnum`.</Word>

<Word name="scriptnum>" stack="( -- n)">Decodes the top of the script stack as a script number (at most 4 bytes) and moves it to the integer stack.</Word>

### Networking

<Word name="wocbitcoinprice" stack="( -- n)">Fetches the bitcoin price in USD and adds it to the stack in pennies. The friendlier spelling `price` dispatches to the same handler.</Word>

<Word name="woccirculatingsupply" stack="(--)">Fetches the circulating supply of bitcoin.</Word>

<Word name="wocgetbalance" stack="(c-addr u -- )">Takes an address string (from `s"`) and displays that address's confirmed balance to the terminal. Usage: `s" 1A1zP1..." wocgetbalance`. For the active wallet's balance as a stack value, use `balance`.</Word>

<Word name="wocgetblockbyheight" stack="(n--)">Takes a block height from the stack and searches WhatsOnChain for info on that block.</Word>

The three words below are *awaitable*: each suspends the line while its network query runs and resumes with the value pushed, so chain state lands on the stack instead of being prose in the transcript — `: pay-rent balance 1000 > if 1000 s" 1A1zP1..." send then ;` is both a Forth word and a payment policy. One query may be in flight at a time; while it runs the terminal shows `awaiting balance… (esc cancels · times out in 30s)` — Escape cancels it, and a query that hasn't answered within 30 seconds times out and halts the line. A query that cannot answer halts the line with an error — never a sentinel value that could silently flip an `if`.

<Word name="balance" stack="( -- sats)">Queries the chain for the active wallet's total balance and pushes it in satoshis. The line suspends while the query runs and resumes when the value lands. A failed or partial query halts the line with an error — never a silent low number.</Word>

<Word name="tx-confirmations" stack="(c-addr u -- n)">Takes a txid string (from `s"`) and pushes the transaction's confirmation count. Pushes 0 when the transaction is known but still unconfirmed in the mempool. An unknown txid halts the line with an error.</Word>

<Word name="spv-verified?" stack="(c-addr u -- flag)">Takes a txid string (from `s"`) and pushes -1 when the transaction's Merkle proof verifies against the locally-validated header chain, 0 when it does not. A header-chain gap prints SPV PENDING alongside the 0; a proof-fetch failure halts the line with an error.</Word>

### Transaction Builder

The transaction builder words allow programmatic construction of Bitcoin transactions directly from the FORTH terminal. Build a transaction step by step, then broadcast it.

<Word name="tx-new" stack="( -- )">Initialises a new transaction builder. Clears any previous transaction state.</Word>

<Word name="tx-set-fee" stack="(n -- )">Sets the fee rate in satoshis per kilobyte for the current transaction. Usage: `500 tx-set-fee`.</Word>

<Word name="tx-add-output" stack="(n c-addr u -- )">Adds a P2PKH output to the transaction. Takes the amount in satoshis plus an address string (from `s"`) — the same convention as `send`. One address per call. Usage: `1000 s" 1A1zP1..." tx-add-output`.</Word>

<Word name="tx-add-data" stack="( -- )">Adds an OP_RETURN data output to the current transaction.</Word>

<Word name="tx-preview-toggle" stack="( -- )">Toggles preview mode. When ON, TX-BROADCAST shows the transaction without sending it; when OFF, TX-BROADCAST broadcasts.</Word>

<Word name="tx-show" stack="( -- )">Displays the current transaction being built (inputs, outputs, fee).</Word>

<Word name="tx-clear" stack="( -- )">Clears the transaction builder, discarding all inputs and outputs.</Word>

<Word name="tx-broadcast" stack="( -- )">Builds, signs, and broadcasts the current transaction to the BSV network via ARC. The legacy spelling `tx-build` dispatches to the same handler.</Word>

<Word name="send" stack="( amount c-addr u -- )">Standard payment in a single word. Pops the destination string from the data stack (placed there by `S"`) and the amount from the integer stack. The string holds one address (single recipient) or N space-separated addresses (equal-split). Validates the inputs, then presents PayView with the amount + address pre-filled. The user long-presses to confirm; Face ID gates the actual broadcast via ARC. Terminal output on success: `sent TXID: <id>`. Usage: `1000 s" 1A1zP1..." send`.</Word>

<Word name="send-many" stack="( amount1 ... amountN c-addr u -- )">Multi-recipient payment with per-recipient amounts. Pops the address string first to derive N (the recipient count), then pops N amounts. Pairs amount[i] with address[i] in left-to-right order. Validates every payee, then presents MultiPaySheet with a per-recipient grid so the user reviews the output set before Face ID. > **Standard Payment Example.** Single recipient: `1000 s" 1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa" send`. Equal-split across multiple: `5000 s" 1A1zP1... 1BvBMS..." send` (2,500 sats each). Multi-recipient with different amounts: `1000 5000 250 s" 1A1zP1... 1BvBMS... 1FfmbHfn..." send-many`.

### On-Chain Archive

`xtext` and `xmedia` are the on-chain archive words: they write X profiles into Bitcoin transactions, read back publicly at henceforth.club/folklore. Fetching is never free — the archive endpoints demand a small on-chain payment before each read — while inscribing costs the miner fee plus a reward that routes to the handle's owner once they have bound the handle to a wallet key.

<Word name="xtext" stack="( c-addr u -- )">Archives an X profile on-chain. Takes a handle string (from `s"`). The fetch itself is paid: the archive endpoint demands a small on-chain fee per read, broadcast from the active wallet — the fee and its txid print to the terminal. The archive sheet then opens with Text / Images / Videos toggles and a live cost; PAY inscribes the archive JSON, a 1Sat Ordinal per selected photo, and the archive reward. Incremental — only posts not yet on-chain are inscribed. Finished archives are public at henceforth.club/folklore. Usage: `s" jack" xtext`.</Word>

<Word name="folklore-sync" stack="( - )">Syncs the folklore board's index into the account's folklore file. One delta fetch against the server's watermark — only transaction identifiers added since the last sync come down, and the file's watermark adopts the server's own clock, so device time can never open a gap. Prints `folklore: N new, M total · synced date` on success, or the offline line with the file untouched. The file is created with the account; content downloads stay lazy — the sync fetches the list, never the bodies. Usage: `folklore-sync`.</Word>

<Word name="xmedia" stack="( c-addr1 u1 c-addr2 u2 -- )">Inscribes a local media file into an X archive as a post of its own — the counterpart to `xtext`, for media the fetch can never reach: a deleted post's video, or anything that only exists as a file you saved. Takes two `s"` strings — the handle, then the filename — read from the app's Files tab. No X API call, so no fetch fee: only the miner fee and the archive reward. Images (jpg, png, gif, webp) and video (mp4, mov) only; the handle must already have an archive. Raises the archive sheet with the cost; PAY writes it to chain. Usage: `s" jack" s" clip.mp4" xmedia`.</Word>

### Script Recording

Script recording is a macro assembler for Bitcoin Script. When recording is active, `op_*` words emit their opcodes into a script buffer rather than executing. Standard FORTH control flow still runs normally.

<Word name="script-begin" stack="( -- )">Start recording Bitcoin Script. `op_*` words emit opcodes to the script buffer. FORTH control flow still runs normally.</Word>

<Word name="script-end" stack="( -- )">Stop recording and finalise the script. Displays the compiled script hex.</Word>

<Word name="script-show" stack="( -- )">Display the current script buffer contents as hex.</Word>

<Word name="script-clear" stack="( -- )">Discard the current script buffer and stop recording.</Word>

<Word name="script-use" stack="( -- )">Set the recorded script as the selected transaction script (for building transactions).</Word>

<Word name="script-save" stack="( -- )">Save the current script with a name. Usage: `script-save <name>`.</Word>

<Word name="script-load" stack="( -- )">Load a previously saved script by name. Usage: `script-load <name>`.</Word>

<Word name="script-list" stack="( -- )">List all saved scripts.</Word>

<Word name="script-step" stack="( -- )">Executes the next opcode of the loaded script buffer against the live script context and renders the stack — single-stepping through real Bitcoin Script. Reset by `script-load`, `script-begin`, `script-clear`, and `clear`.</Word>

> **Raw bytes require a `0x` prefix during recording.** A bare hex-looking token such as `ff` is *not* emitted as the byte `0xff` — it is parsed according to the current `BASE` and pushed to the integer stack. To emit raw opcode bytes into the script buffer, use an explicit `0x`-prefixed literal (e.g. `0xdeadbeef`).

<a id="ref-opcodes" />

### OPCodes

All 140+ Bitcoin Script opcodes are exposed as FORTH words. Below are the categories — every opcode behaves like its Script consensus definition.

> **Reading the `≈` hint.** Where an opcode has a one-to-one Henceforth FORTH equivalent, you'll see it next to the stack diagram (e.g. `op_dup ≈ dup`, `op_add ≈ +`, `op_swap ≈ swap`). Opcodes without the hint are Script-specific and have no direct FORTH analogue — `op_checksig`, `op_verify`, `op_return`, `op_codeseparator`, the crypto ops, the Chronicle splice ops. Composite mappings (e.g. `op_3dup` = `2dup over`, `op_notif` = `0= if`) appear in the description prose rather than as a single-word hint.

#### Push Data

<Word name="op_0 … op_16" stack="( - x)">Push the corresponding script number onto the script stack as a minimally-encoded byte vector — `op_0` pushes the empty vector (Script's canonical zero). Not equivalent to a FORTH numeric literal: literals land on the integer stack, so `5 3 op_add` errors. Use `>scriptnum` to move an integer onto the script stack.</Word>
<Word name="op_false" stack="( - x)" forth="false">Pushes the empty byte vector (Script canonical zero / FALSE). Alias for OP_0.</Word>
<Word name="op_pushdata1" stack="( - )">Frames a length-prefixed data push during script recording. At the prompt a 0x literal pushes its bytes directly.</Word>
<Word name="op_pushdata2" stack="( - )">Frames a length-prefixed data push during script recording. At the prompt a 0x literal pushes its bytes directly.</Word>
<Word name="op_pushdata4" stack="( - )">Frames a length-prefixed data push during script recording. At the prompt a 0x literal pushes its bytes directly.</Word>
<Word name="op_1negate" stack="( - -1)">Pushes the script number -1 onto the script stack. (FORTH equivalent: `-1`.)</Word>

#### Control Flow

<Word name="op_nop" stack="( - )">Does nothing. Consensus no-op.</Word>
<Word name="op_ver" stack="( - version)">Pushes the transaction version (4-byte little-endian) onto the script stack. Chronicle upgrade of the historically-reserved opcode.</Word>
<Word name="op_if" stack="( x - )" forth="if">Consumes the top item as a consensus boolean and gates the script opcodes that follow.</Word>
<Word name="op_notif" stack="( x - )">Runs the following branch when the top item is false. Mirror image of OP_IF. Composite FORTH: `0= if`.</Word>
<Word name="op_verif" stack="( threshold - bool)">Pushes 1 if the transaction version is at least the threshold. Chronicle upgrade.</Word>
<Word name="op_vernotif" stack="( threshold - bool)">Pushes 1 if the transaction version is below the threshold. Chronicle upgrade.</Word>
<Word name="op_else" stack="( - )" forth="else">Flips the active branch — runs its body when the preceding OP_IF or OP_NOTIF branch did not run.</Word>
<Word name="op_endif" stack="( - )" forth="then">Closes the innermost OP_IF / OP_NOTIF block.</Word>
<Word name="op_verify" stack="( x - )">Pops the top item and fails the script when it is false. Script-specific — no FORTH analogue.</Word>
<Word name="op_return" stack="( - )">Marks the script as failed. In a locking script the data after it is provably unspendable — the standard way to record data on-chain.</Word>

<Word name="op_toaltstack" stack="( x - )" forth="&gt;r">Pops the top item off the main stack and pushes it onto the alt stack.</Word>
<Word name="op_fromaltstack" stack="( - x)" forth="r&gt;">Pops the top item off the alt stack and pushes it onto the main stack.</Word>
<Word name="op_2drop" stack="( x1 x2 - )" forth="2drop">Drops the top two items from the script stack.</Word>
<Word name="op_2dup" stack="( x1 x2 - x1 x2 x1 x2)" forth="2dup">Duplicates the top two items.</Word>
<Word name="op_3dup" stack="( x1 x2 x3 - x1 x2 x3 x1 x2 x3)">Duplicates the top three items. Composite FORTH: `2dup over`.</Word>
<Word name="op_2over" stack="( x1 x2 x3 x4 - x1 x2 x3 x4 x1 x2)" forth="2over">Copies the third and fourth items to the top.</Word>
<Word name="op_2rot" stack="( x1 x2 x3 x4 x5 x6 - x3 x4 x5 x6 x1 x2)">Moves the fifth and sixth items to the top. Composite FORTH: chain of three `rot`s.</Word>
<Word name="op_2swap" stack="( x1 x2 x3 x4 - x3 x4 x1 x2)" forth="2swap">Swaps the top two pairs.</Word>
<Word name="op_ifdup" stack="( x - 0 | x x)" forth="?dup">Duplicates the top item only if it is non-zero.</Word>
<Word name="op_depth" stack="( - n)" forth="depth">Pushes the number of items currently on the script stack.</Word>
<Word name="op_drop" stack="( x - )" forth="drop">Drops the top item from the script stack.</Word>
<Word name="op_dup" stack="( x - x x)" forth="dup">Duplicates the top item on the script stack.</Word>
<Word name="op_nip" stack="( x1 x2 - x2)" forth="nip">Removes the second-from-top item, keeping the top.</Word>
<Word name="op_over" stack="( x1 x2 - x1 x2 x1)" forth="over">Copies the second-from-top item to the top.</Word>
<Word name="op_pick" stack="( ... n - ... xn)" forth="pick">Pops n and copies the n-th item (0-based from top) to the top.</Word>
<Word name="op_roll" stack="( xn ... x0 n - xn-1 ... x0 xn)" forth="roll">Moves the n-th item (0-based from top) to the top.</Word>
<Word name="op_rot" stack="( x1 x2 x3 - x2 x3 x1)" forth="rot">Rotates the top three items left so the third becomes the top.</Word>
<Word name="op_swap" stack="( x1 x2 - x2 x1)" forth="swap">Swaps the top two items on the script stack.</Word>
<Word name="op_tuck" stack="( x1 x2 - x2 x1 x2)" forth="tuck">Copies the top item below the second-from-top item.</Word>

#### Arithmetic

<Word name="op_1add" stack="( x - sum)" forth="1+">Adds one to the top script number.</Word>
