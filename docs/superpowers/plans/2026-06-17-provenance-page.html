Build /provenance — a modernised, unlisted brand page

A dark-aubergine + emerald, serif-headline marketing page for Provenance Partners, living unlisted inside the henceforth-club repo. Spec: docs/superpowers/specs/2026-06-17-provenance-page-design.html.

For agentic workers: REQUIRED SUB-SKILL — use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Execute task-by-task; tick each <input> as you go. Tests: npm run test (vitest, node env, src/**/*.test.ts only — no jsdom/RTL, so view behaviour is verified via npm run build + npm run dev, per the project's testing philosophy). Build gate: npm run build. Commit per task, never amend. Do not git push and do not open the PR — pushing the branch creates the Vercel preview and is Henry's call.

Goal: A premium, modernised Provenance Partners page at henceforth.club/provenance — dark purple field, emerald accent, professional serif type — reachable only by typing the URL (not in nav, not in sitemap, noindex), with the henceforth.club chrome suppressed.

Architecture: A new App-Router route re-skinned with a scoped .provenance CSS-variable override (the proven .paper pattern), appended to globals.css — no existing rules change. Real content lives in a typed content.ts data module; the page maps it to presentational sections reusing FadeIn and the token-driven card/section utilities. The two behavioural invariants (noindex, sitemap-exclusion) are isolated into pure modules and unit-tested in node; everything visual is verified on the build + preview.

Tech stack: Next.js 16 (App Router, server/client components), React 19, Tailwind v4 (@theme inline, no config), next/font/google (Fraunces + Inter), Motion (FadeIn), vitest (node), npm, Vercel.

Global constraints

  • Stack floor: Next.js 16 App Router · React 19 · Tailwind v4 via @theme inline (there is no tailwind.config) · TypeScript strict · npm.
  • Tests are node-only (src/**/*.test.ts, no jsdom). Unit-test pure data only; verify the view via npm run build + npm run dev.
  • Palette (scoped, AA-verified): bg #1e1526 · fg #ece8ef · muted #a294a8 · card #271a30 · border #3a2844 · brand-purple #5a3d68 (fill/border only) · emerald #34d17a · bright #5ef0a0.
  • CTA is dark-on-green (#0a1f12 on #34d17a). White-on-emerald (1.99:1) is banned.
  • No Space Mono anywhere on this route — serif headlines (Fraunces), sans body (Inter).
  • Unlisted: never add /provenance to Navbar or sitemap.ts; the route is robots: {index:false, follow:false}.
  • Append-only to globals.css — do not edit existing rules. The only edits to shared files are the two chrome guards (Task 7).
  • Git: work on branch feat/provenance-page; commit per task; never amend; do not push / open PR (Henry's call).
