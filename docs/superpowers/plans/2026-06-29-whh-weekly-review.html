Implementation Plan · henceforth-club · branch feat/whh-weekly-review

/whh — the weekly review

A hand-run /whh command that aggregates the week's daily /hh artifacts, pulls real App Store Connect sales, has an ultracode agent layer write the judgement, and publishes the whole thing to a gated /board/week page readable from any device.

Implements docs/superpowers/specs/2026-06-29-whh-weekly-review-design.html (approved 2026-06-29). Every path, schema, and convention below was verified by a four-agent read-only investigation of the live /hh artifacts and the henceforth-club codebase. Execute task-by-task.

For agentic workers: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps are real checkboxes. Phase 0 is a gate for the sales half only — the retrospective half and the entire website plumbing build and verify without any App Store Connect credentials. The pure core (Phases 1–2) is TDD — failing tests first, they are the definition of done, run via vitest. The feature adds zero new npm dependencies and zero middleware changes. Commit after each task.

Design summary — what we settled

  • Two halves, decoupled. The retrospective (how the week went, how to do better) aggregates data that already exists — no new credentials. The sales half (drive more sales) needs App Store Connect and is gated on Phase 0 inputs. Either can ship without the other.
  • Hybrid engine. A deterministic aggregator owns every number (totals, throughput, deltas, recurring-reflag counts); an ultracode Workflow owns every judgement (wins, misses, next-week actions, sales drivers). Synthesis reads the numbers as ground truth and never recomputes them.
  • The page only renders. Like report/page.tsx, /board/week renders the published weeks/<date>.json from Upstash (local-file fallback). The aggregator + App Store Connect pull run offline inside /whh; the page is a trivial, fully-gated server component.
  • Zero new dependencies. Vitest already exists. The App Store Connect ES256 JWT is minted with built-in node:crypto (dsaEncoding:"ieee-p1363" emits the JOSE signature directly); the gzipped sales report unpacks with built-in node:zlib. No jose, no jsonwebtoken.
  • Sales covers three App Store apps — Henceforth (id1602896145), DaDeckOfCards (id1520654142), Hansard — and excludes Provenance (an operational watcher, not an App Store app).
  • Credentials stay local. Issuer id / key id / vendor number / .p8 path live in .env.local (gitignored, beside the existing KV_REST_API_*); the .p8 stays at ~/.appstoreconnect/. Only computed aggregates reach Upstash and the website.
  • Recurring re-flags from report findings (v1). The week's reports/<date>.json findings already carry the signal (they self-number — "5th re-flag", "8th dismissal"), so v1 derives re-flags from them. Parsing the committed markdown corrections ledgers is a documented follow-on, not in this plan.
  • Sales Tier 1 now, Tier 2 later. This plan ships Tier 1 (units + proceeds + week-over-week). Tier 2 — the App Analytics impressions→conversion funnel — is a documented follow-on that lights up once its report request has been live a couple of days; the page degrades gracefully without it, and drivers fall back to units/proceeds trend plus qualitative App Store optimisation.

Global constraints

  • Package manager: this repo uses npm (not bun). Commands: npm run build, npm run lint, npm test (= vitest run).
  • Modules: package.json has no "type" field → scripts use the .mjs extension for ES modules. New scripts match scripts/board/*.mjs exactly.
  • Upstash: publishers construct new Redis({ url, token }) reading KV_REST_API_URL || UPSTASH_REDIS_REST_URL and the matching token; redis.set(key, obj) is passed the object directly (no JSON.stringify). Pages use the lazy getRedis() from @/lib/redis, never a direct client.
  • Gating: src/middleware.ts matcher ["/board", "/board/:path*"] already gates /board/week. Do not modify it.
  • Git: branch + pull-request workflow; no direct main push, no force-push. Work on feat/whh-weekly-review (already created off feat/board-plan-and-docs; the spec is its first commit).
  • Prose: no acronyms / initialisms in any committed text or chat — spell things out ("pull request", "continuous integration", "App Store review").
  • App Store apps for sales: henceforth, deck, hansard. Provenance excluded.
  • App→accent tokens (for the page): henceforth → text-accent-warm (amber), hansard → text-accent-green (green), deck → text-accent (cyan).

/** @returns {string[]} trailing `days` calendar dates ending `endDate`, ascending. */
export function windowDates(endDate, days = 7) {
  const end = new Date(`${endDate}T00:00:00Z`);
  const out = [];
  for (let i = days - 1; i >= 0; i--) {
    const d = new Date(end);
    d.setUTCDate(end.getUTCDate() - i);
    out.push(d.toISOString().slice(0, 10));
  }
  return out;
}

    export function parseSurvived(value) {
  if (typeof value === "number") return { survived: value, total: value };
  if (typeof value !== "string") return { survived: 0, total: 0 };
  const m = value.match(/(\d+)\s*\/\s*(\d+)/);
  return m ? { survived: Number(m[1]), total: Number(m[2]) } : { survived: 0, total: 0 };
}

const SUMMARY_KEYS = ["reviews","confirmed","rejected","abstained","alreadyResolved","skipped","newConfirmedDefects","boardMoves"];

export function aggregateTotals(reports) {
  const totals = Object.fromEntries(SUMMARY_KEYS.map((k) => [k, 0]));
  let survived = 0, survivedTotal = 0;
  for (const r of reports) {
    const s = r.summary ?? {};
    for (const k of SUMMARY_KEYS) totals[k] += Number(s[k] ?? 0);
    const v = parseSurvived(s.verdictsSurvivedRefutation);
    survived += v.survived; survivedTotal += v.total;
  }
  return { ...totals, verdictsSurvived: survived, verdictsTotal: survivedTotal };
}

    const VERDICTS = ["confirm","reject","abstain","already-resolved"];

export function perApp(reports) {
  const byApp = new Map();
  for (const r of reports) for (const a of r.apps ?? []) {
    const cur = byApp.get(a.app) ?? { app: a.app, name: a.name ?? a.app, reviews: 0, confirm: 0, reject: 0, abstain: 0, "already-resolved": 0 };
    if (a.reviewFound) cur.reviews += 1;

    byApp.set(a.app, cur);
  }
  return [...byApp.values()];
}

export function ratios(t) {
  const confirmRejectRatio = t.rejected === 0 ? null : t.confirmed / t.rejected;
  const adjudicated = t.confirmed + t.rejected + t.abstained;
  const abstainRate = adjudicated === 0 ? 0 : t.abstained / adjudicated;
  const survivedRefutation = t.verdictsTotal === 0 ? null : t.verdictsSurvived / t.verdictsTotal;
  return { confirmRejectRatio, abstainRate, survivedRefutation };
}

    export function reflagSignature(title) {
  return String(title)
    .replace(/\s*[—-]\s*\d+(st|nd|rd|th)\s+re-?flag.*$/i, "")
    .replace(/\s*[—-]\s*already carded.*$/i, "")
    .replace(/\d{4}-\d{2}-\d{2}/g, "")
    .trim().toLowerCase();
}

const ORDINAL = /(\d+)(?:st|nd|rd|th)\s+(?:re-?flag|dismissal)/i;

export function recurringReflags(reports) {
  const groups = new Map();
  for (const r of reports) for (const a of r.apps ?? []) for (const f of a.findings ?? []) {
    const sig = reflagSignature(f.title);
    if (!sig) continue;
    const key = `${a.app}::${sig}`;
    const g = groups.get(key) ?? { signature: sig, app: a.app, title: f.title, days: [], verdicts: [], maxOrdinal: 0 };
    g.days.push(r.date); g.verdicts.push(f.verdict);
    const m = `${f.title} ${f.recommendation ?? ""}`.match(ORDINAL);
    if (m) g.maxOrdinal = Math.max(g.maxOrdinal, Number(m[1]));
    groups.set(key, g);
  }
  return [...groups.values()]
    .filter((g) => g.days.length > 1 || g.maxOrdinal >= 2)
    .map((g) => ({
      signature: g.signature, app: g.app, title: g.title,
      timesFlagged: Math.max(g.days.length, g.maxOrdinal),
      firstSeen: g.days.slice().sort()[0],
      status: g.verdicts.every((v) => v === "reject") ? "serially-rejected"
            : g.verdicts.includes("already-resolved") ? "resolved" : "mixed",
    }))
    .sort((a, b) => b.timesFlagged - a.timesFlagged);
}

    export function earliestDateIn(text) {
  const m = String(text).match(/\d{4}-\d{2}-\d{2}/g);

export function throughput(board, windowStart) {
  const cards = board?.cards ?? [];
  const census = {};
  for (const c of cards) census[c.col] = (census[c.col] ?? 0) + 1;
  const stuck = cards
    .filter((c) => c.col === "inprogress" || c.col === "review")
    .map((c) => ({ id: c.id, title: c.title, app: (c.apps ?? [])[0] ?? "*", col: c.col, firstSeen: earliestDateIn(`${c.id} ${c.source ?? ""} ${c.desc ?? ""}`) }))
    .filter((c) => c.firstSeen && c.firstSeen < windowStart)
    .sort((a, b) => (a.firstSeen < b.firstSeen ? -1 : 1));
  return { columnCensus: census, doneCount: census.done ?? 0, stuck };
}

export function buildRetro({ reports, board, windowStart }) {

    totals: Object.fromEntries(SUMMARY_KEYS.map((k) => [k, totals[k]])),
    perApp: perApp(reports),
    throughput: throughput(board, windowStart),
    recurringReflags: recurringReflags(reports),
    ratios: ratios(totals),
    wins: [], misses: [], nextWeek: [],
  };
}

const b64url = (buf) => Buffer.from(buf).toString("base64url");

/** Short-lived ES256 JWT for the App Store Connect API. */
export function mintJWT({ issuerId, keyId, privateKeyPem, now = Math.floor(Date.now() / 1000), ttl = 1200 }) {
  const header = { alg: "ES256", kid: keyId, typ: "JWT" };
  const payload = { iss: issuerId, iat: now, exp: now + ttl, aud: "appstoreconnect-v1" };
  const input = `${b64url(JSON.stringify(header))}.${b64url(JSON.stringify(payload))}`;
  const signature = sign("sha256", Buffer.from(input), { key: createPrivateKey(privateKeyPem), dsaEncoding: "ieee-p1363" });
  return `${input}.${b64url(signature)}`;
}

    return { sku: c[iSku], title: c[iTitle], units: Number(c[iUnits] ?? 0), proceeds: Number(c[iProc] ?? 0), currency: c[iCur] };
  });
}

export function sumByApp(rows, appSkus) {
  const out = {};
  for (const [app, skus] of Object.entries(appSkus)) {
    const matched = rows.filter((r) => skus.includes(r.sku));
    out[app] = {
      units: matched.reduce((n, r) => n + r.units, 0),
      proceeds: matched.reduce((n, r) => n + r.proceeds, 0),
      currency: matched[0]?.currency ?? null,
    };
  }
  return out;
}

export function delta(thisWeek, lastWeek) {
  if (lastWeek === 0) return thisWeek === 0 ? 0 : null;
  return (thisWeek - lastWeek) / lastWeek;
}

/** Assemble the sales half: this-week vs last-week units/proceeds per app. */
export async function pullSales({ creds, appSkus, names, thisDate, lastDate, fetchImpl = fetch }) {
  const jwt = mintJWT(creds);
  const [now, prev] = await Promise.all([
    fetchSalesReport({ jwt, vendorNumber: creds.vendorNumber, reportDate: thisDate, fetchImpl }),
    fetchSalesReport({ jwt, vendorNumber: creds.vendorNumber, reportDate: lastDate, fetchImpl }),
  ]);
  const a = sumByApp(now, appSkus), b = sumByApp(prev, appSkus);
  const perApp = Object.keys(appSkus).map((app) => ({
    app, name: names[app] ?? app,
    units: { thisWeek: a[app].units, lastWeek: b[app].units, deltaPct: delta(a[app].units, b[app].units) },
    proceeds: { thisWeek: a[app].proceeds, lastWeek: b[app].proceeds, currency: a[app].currency ?? b[app].currency, deltaPct: delta(a[app].proceeds, b[app].proceeds) },
  }));
  return { window: { thisWeek: thisDate, lastWeek: lastDate }, perApp, drivers: [] };
}

function ascFromEnv(dates) {
