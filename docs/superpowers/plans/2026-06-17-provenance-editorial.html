Rebuild /provenance as a high-end editorial site

Re-theme the existing /provenance route to an editorial, photography-led, premium design. Spec: docs/superpowers/specs/2026-06-17-provenance-editorial-design.html.

For agentic workers: the route, its guards (noindex test, sitemap test, Navbar/SiteFooter suppression) and content.ts already exist and pass — this plan re-themes the look. Most tasks are build (verified by npm run build + the existing tests) and the finale is a visual screenshot-iteration loop. Tests: npm run test (node-env vitest). Build: npm run build. Commit per task, never amend. Do not git push until the visual gate passes — push creates the Vercel preview for Henry; merge to main is Henry's call.

Goal: /provenance reads as a genuinely premium editorial produce site — Fraunces display type, big photography, generous whitespace, green as the only accent, purple a whisper — with all real content and the unlisted guards intact.

Architecture: Same Next 16 / Tailwind v4 .provenance scoped-token approach. Swap fonts to Fraunces + DM Sans, rebuild page.tsx and its section components editorially, and place a photography set under public/provenance/editorial/ that is swap-in-place for real photos later. Quality is reached by iterating the rendered page against screenshots, not by unit tests (the page is presentational; the two behavioural guards already exist).

Tech stack: Next 16 App Router, React 19, Tailwind v4 (@theme inline), next/font/google (Fraunces + DM Sans), Motion (FadeIn), vitest (node), headless Chrome for screenshots.

Global constraints

  • Palette: white bg · charcoal text/headings #2a2e33 (NOT purple) · muted #6f6b78 · green #7cce2a = accent fills only (never green text on white) · purple #330a49 = whisper (logo + at most one tiny detail) · CTA = green fill + dark text.
  • Type: Fraunces (serif display) + DM Sans (body). No monospace on the route.
  • Editorial: big imagery, large type scale, generous whitespace, restraint.
  • Photography swap-able: all images under public/provenance/editorial/; replacing a file must not require layout changes. v1 = CC stand-ins.
  • Unlisted invariant (already in place — keep green): not in nav/sitemap, robots:{index:false}; Navbar + SiteFooter return null on the route.
  • Append/scope only in globals.css (edit the existing .provenance block; touch no other rule). Git: branch feat/provenance-page (already exists), commit per task, no push until the visual gate.

Task 2 — Fonts + scoped theme build

In globals.css .provenance block, repoint the font vars (leave the colour tokens — they're already the light editorial palette): 
  --font-serif: var(--font-fraunces), Georgia, serif;
  --font-sans:  var(--font-dm-sans), system-ui, sans-serif;
Leave the existing body:has(.provenance), ::selection and noise-disable rules as they are.
In layout.tsx, load the fonts and apply both variables 
import { Fraunces, DM_Sans } from "next/font/google";
const fraunces = Fraunces({ subsets:["latin"], variable:"--font-fraunces", display:"swap" });
const dmSans = DM_Sans({ subsets:["latin"], variable:"--font-dm-sans", display:"swap", weight:["400","500","700"] });
// wrapper className: `provenance font-sans min-h-screen bg-background text-foreground ${fraunces.variable} ${dmSans.variable}`
Keep the header (logo + section nav + green Contact) and the neutral footer from the current layout; just change the fonts. Run npm run build → exit 0. Commit: feat(provenance): Fraunces + DM Sans editorial type.

Task 3 — Editorial section components build

Build the editorial section pieces in _components/ (server components; next/image for photos with fill + object-cover; Fraunces via font-serif):
  • HeroEditorial.tsx — full-width or 60/40 hero: a large hero.jpg with a restrained Fraunces headline ("Globally sourced exotic vegetables."), one-line sub, one green CTA. Balanced — image is a backdrop/side, not a single oversized vegetable; headline legible over a soft scrim.
  • Story.tsx — two-column: story.jpg + the ABOUT narrative + 3-4 elegant stats (Est. 2011 · year-round · UK retail/processing/food-service).
  • Reuse ValueCard/ValueIcon but restyle editorial (lighter weight, more air); reuse ProductChip or render products as a typographic index; reuse AccreditationRow (logos on white).
All colours via tokens / the constraint palette; green only as fills; headings text-[#2a2e33] in font-serif.

Task 4 — Compose the page build

Rebuild page.tsx to compose the sections in order: Hero → Story → Values (all 8) → Products (full range) → Accreditations → Suppliers → Contact (mailto + Modern Slavery PDF). Keep export const metadata = { ..., robots } (noindex) and FadeIn on sections. Import content from content.ts. Run npm run test (34/34 green) + npm run build (exit 0, /provenance prerenders). Commit: feat(provenance): editorial page composition.

Task 5 — Visual polish loop visual

Gate (iterate until premium): run a local prod server, screenshot /provenance with headless Chrome, and look. Adjust hero composition, type scale, spacing, image crops, section rhythm — re-screenshot — repeat until it genuinely reads high-end editorial. Checklist: (1) hero balanced & headline legible; (2) no green-block placeholders, no oversized-vegetable hero; (3) Fraunces display + DM Sans body, ample whitespace; (4) green accent only, purple a whisper, charcoal headings; (5) all real content present; (6) /provenance has no henceforth nav/footer, homepage unchanged; (7) npm run test + npm run build green.
Screenshot, refine, repeat; commit when it reads premium.
