The ledger, implemented

Ten tasks taking Henceforth Bitcoin Limited's accounts from a CSV file to a gated, editable table with a Merkle root per accounting period committed on chain. Tasks 1 to 8 deliver the thing that unblocks the filing; 9 and 10 are the chain.

For agentic workers: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this task by task. Steps are real checkboxes. Spec: docs/superpowers/specs/2026-07-30-ledger-webapp-design.html.

Goal. A gated, editable ledger at /board/ledger backed by Upstash, committing one Merkle root per accounting period on chain and exporting per-transaction inclusion proofs.

Architecture. Four pure modules under src/lib/ledger/ — money, periods, validation, Merkle — none of which perform any input or output, so all of them are testable without a network or a store. A thin Upstash layer and one gated route sit above them, and a React client renders the table. Broadcast runs from a local Node script, never from a deployed route.

Tech stack. Next.js 16 App Router, React 19, Tailwind v4, @upstash/redis, @bsv/sdk, vitest. All already dependencies; nothing new is installed.

Global constraints

Every task's requirements implicitly include these.

  • Money is a decimal string, arithmetic is in integer pence. No value representing money may be held in a JavaScript number outside pence-integer form. This is the defect the source spreadsheet carried (2589.659999999998).
  • Merkle: an odd node is carried up unchanged, never duplicated. Non-negotiable, and unfixable once roots are broadcast.
  • Merkle: leaves and internal nodes are domain-separated. Leaf hashes are prefixed L:, internal nodes N:, so a leaf can never be reinterpreted as an internal node.
  • /api/ledger must gate on verifySession itself. src/middleware.ts matches ["/board", "/board/:path*"] only. The page is gated by middleware; the endpoint is not, and would otherwise be public.
  • A committed period is read-only at both the endpoint and the interface.
  • No test may broadcast or spend. Broadcast is exercised only through the dry-run path.
  • Accounts: HSBC (debit), HSBC (credit), NatWest, Amex (credit).
  • Categories: Statutory filing fees, Internet, Website, Software subscriptions, Training, Equipment, Phone, Tax payment, App revenue, Uncategorised.
  • No acronyms or initialisms in prose — user-visible copy, commit messages, pull request descriptions. Code identifiers are exempt.
  • Test command: npm test (vitest run). Build gate: npm run build.
Refinement to Decision 3 of the spec. The spec says the broadcast is server-side, reusing the board archive key. In practice that means a local Node script, exactly as scripts/board/render-pdf.mjs already does — not a deployed route. A Vercel route would require a funded private key in the deployment environment, spendable by anyone with dashboard access or through a compromised build, to serve a job that runs about four times a year. The page reads commitment status from Upstash; only Henry's machine can broadcast.

const AMOUNT = /^(-?)(\d+)\.(\d{2})$/;

/** Signed pence, or null if the string is not exactly a two-place figure. */
export function parseAmount(s: string): number | null {
  const m = AMOUNT.exec(s ?? "");
  if (!m) return null;
  const [, sign, whole, frac] = m;
  const pence = Number(whole) * 100 + Number(frac);
  if (!Number.isSafeInteger(pence)) return null;
  return sign === "-" ? -pence : pence;
}

export function formatPence(pence: number): string {
  const sign = pence < 0 ? "-" : "";
  const abs = Math.abs(pence);
  return `${sign}${Math.floor(abs / 100)}.${String(abs % 100).padStart(2, "0")}`;
}

/** Malformed entries contribute nothing; validation rejects them upstream. */
export function sumPence(amounts: string[]): number {
  return amounts.reduce((total, a) => total + (parseAmount(a) ?? 0), 0);
}

import type { Period } from "./types";

// Henceforth Bitcoin Limited, registration 13829963. The accounting reference
// date moved twice: originally 31 January, shortened to 31 December for the
// eleven-month period ending 2024-12-31. Calendar years only align from 2025.
const RANGES: ReadonlyArray<[string, string, string]> = [
  ["2021-12-01", "2023-01-31", "incorporation to 31 January 2023"],
  ["2023-02-01", "2024-01-31", "01 February 2023 to 31 January 2024"],
  ["2024-02-01", "2024-12-31", "01 February 2024 to 31 December 2024"],
  ["2025-01-01", "2025-12-31", "01 January 2025 to 31 December 2025"],
  ["2026-01-01", "2026-12-31", "01 January 2026 to 31 December 2026"],
];

export const PERIODS: readonly Period[] = RANGES.map(([start, end, label]) => ({
  id: `${start}_${end}`, label, start, end,
}));

export function periodFor(date: string): Period | null {
  return PERIODS.find((p) => date >= p.start && date <= p.end) ?? null;
}

export function periodById(id: string): Period | null {
  return PERIODS.find((p) => p.id === id) ?? null;
}

    String comparison is correct here precisely because the dates are ISO 8601: lexicographic order and chronological order coincide. That is the whole reason the conversion normalised them.

    // src/lib/ledger/validate.ts
import { parseAmount } from "./money";
import { periodFor } from "./periods";
import type { Transaction } from "./types";

const ISO_DATE = /^\d{4}-\d{2}-\d{2}$/;

function isRealDate(s: string): boolean {
  const d = new Date(`${s}T00:00:00Z`);
  return !Number.isNaN(d.getTime()) && d.toISOString().slice(0, 10) === s;
}

export function validateTransaction(t: Partial<Transaction>): string[] {
  const errors: string[] = [];
  const date = t.date ?? "";

  if (!ISO_DATE.test(date) || !isRealDate(date)) {
    errors.push(`date: ${JSON.stringify(date)} must be YYYY-MM-DD — a spreadsheet may have rewritten it`);
  } else if (!periodFor(date)) {
    errors.push(`date: ${date} falls outside every known accounting period`);
  }

  if (parseAmount(t.amount ?? "") === null) {
    errors.push(`amount: ${JSON.stringify(t.amount ?? "")} must be signed with exactly two decimal places`);
  }

  if (!(t.description ?? "").trim()) errors.push("description: must not be empty");

  return errors;
}

    Note the ordering: an unparseable date reports as a date problem, and only a valid date is then checked for period membership. Reporting both for one bad string would be noise.

Task 4 · The Merkle tree no second chance

Files: Create src/lib/ledger/merkle.ts, src/lib/ledger/merkle.test.ts

Consumes: Transaction; sha256Hex from @/lib/board-auth. Produces: canonicalise, leafHash, buildRoot, buildProof, verifyProof.

Two rules that cannot be retrofitted. An odd node is carried up unchanged rather than duplicated, which closes the duplicate-leaf ambiguity where two different sets hash to one root. And leaves are domain-separated from internal nodes by a prefix, so a leaf can never be presented as an internal node. Both are cheap now and impossible later, because by then roots are broadcast.

    // src/lib/ledger/merkle.ts
import { sha256Hex } from "@/lib/board-auth";
import type { Transaction } from "./types";

export type ProofStep = { hash: string; side: "left" | "right" };

const FIELDS = ["id","date","account","amount","description","category","source"] as const;

/**
 * Fixed field order, unit-separator delimited. Record separators cannot occur
 * in any field, so the encoding is unambiguous without escaping.
 */
export function canonicalise(t: Transaction): string {
  return FIELDS.map((f) => String(t[f] ?? "").replace(//g, " ")).join("");
}

export function leafHash(t: Transaction): Promise<string> {
  return sha256Hex(`L:${canonicalise(t)}`);
}

function nodeHash(left: string, right: string): Promise<string> {
  return sha256Hex(`N:${left}${right}`);
}

/** Leaves must already be sorted. An odd node is carried up, never duplicated. */
export async function buildRoot(leaves: string[]): Promise<string> {
  if (leaves.length === 0) throw new Error("cannot commit an empty period");
  let level = leaves;
  while (level.length > 1) {
    const next: string[] = [];
    for (let i = 0; i < level.length; i += 2) {
      next.push(i + 1 < level.length ? await nodeHash(level[i], level[i + 1]) : level[i]);
    }
    level = next;
  }
  return level[0];
}

/** The sibling path from a leaf to the root. Carried-up nodes contribute nothing. */
export async function buildProof(leaves: string[], index: number): Promise<ProofStep[]> {
  if (index < 0 || index >= leaves.length) throw new Error("leaf index out of range");
  const steps: ProofStep[] = [];
  let level = leaves;
  let i = index;
  while (level.length > 1) {
    const isRight = i % 2 === 1;
    const siblingIndex = isRight ? i - 1 : i + 1;
    if (siblingIndex < level.length) {
      steps.push({ hash: level[siblingIndex], side: isRight ? "left" : "right" });
    }
    const next: string[] = [];
    for (let j = 0; j < level.length; j += 2) next.push(level[j]); // WRONG — see warning
    level = next;
    i = Math.floor(i / 2);
  }
  return steps;
}

export async function verifyProof(leaf: string, steps: ProofStep[], root: string): Promise<boolean> {
  let acc = leaf;
  for (const { hash, side } of steps) {
    acc = side === "left" ? await nodeHash(hash, acc) : await nodeHash(acc, hash);
  }
  return acc === root;
}
    Implementer's warning. The buildProof body above collapses each level with a placeholder that keeps only the left element, which produces the right shape but the wrong sibling hashes above level zero. Replace that inner loop with the real level reduction — the same one buildRoot performs, awaiting nodeHash — and make the function async. The test that verifies every leaf in a five-leaf tree is what catches this; do not weaken it to a two-leaf case, because a two-leaf tree has no level above zero and would pass with the bug intact.

import { getRedis } from "@/lib/redis";
import { PERIODS } from "./periods";
import type { Commit, Transaction } from "./types";

const TRANSACTIONS = "ledger:transactions";
const commitKey = (periodId: string) => `ledger:commit:${periodId}`;

export async function loadTransactions(): Promise<Transaction[]> {
  const redis = getRedis();
  if (!redis) return [];
  return (await redis.get<Transaction[]>(TRANSACTIONS)) ?? [];
}

export async function saveTransactions(list: Transaction[]): Promise<void> {
  const redis = getRedis();
  if (!redis) throw new Error("no store configured");
  await redis.set(TRANSACTIONS, list);
}

export async function loadCommit(periodId: string): Promise<Commit | null> {
  const redis = getRedis();
  if (!redis) return null;
  return (await redis.get<Commit>(commitKey(periodId))) ?? null;
}

export async function saveCommit(commit: Commit): Promise<void> {
  const redis = getRedis();
  if (!redis) throw new Error("no store configured");
  await redis.set(commitKey(commit.periodId), commit);
}

export async function loadAllCommits(): Promise<Record<string, Commit>> {
  const entries = await Promise.all(
    PERIODS.map(async (p) => [p.id, await loadCommit(p.id)] as const),
  );
  return Object.fromEntries(entries.filter(([, c]) => c !== null)) as Record<string, Commit>;
}

/** Minimal reader for the quoting the export actually produces. */
function parseCsv(text) {
  const rows = [];
  let row = [], field = "", quoted = false;
  for (let i = 0; i < text.length; i++) {
    const c = text[i];
    if (quoted) {
      if (c === '"' && text[i + 1] === '"') { field += '"'; i++; }
      else if (c === '"') quoted = false;
      else field += c;
    } else if (c === '"') quoted = true;
    else if (c === ",") { row.push(field); field = ""; }
    else if (c === "\n") { row.push(field); rows.push(row); row = []; field = ""; }
    else if (c !== "\r") field += c;
  }
  if (field || row.length) { row.push(field); rows.push(row); }
  return rows.filter((r) => r.some((f) => f !== ""));
}

    // src/app/api/ledger/route.ts
import { NextResponse } from "next/server";
import { cookies } from "next/headers";
import { verifySession } from "@/lib/board-auth";
import { loadCommit, loadTransactions, saveTransactions } from "@/lib/ledger/store";
import { validateTransaction } from "@/lib/ledger/validate";
import { periodFor } from "@/lib/ledger/periods";
import type { Transaction } from "@/lib/ledger/types";

export const runtime = "nodejs";

async function authorised(): Promise<boolean> {
  const secret = process.env.BOARD_COOKIE_SECRET ?? "";
  if (!secret) return false;
  return verifySession((await cookies()).get("board_session")?.value, secret);
}

const deny = () => NextResponse.json({ error: "unauthorized" }, { status: 401 });

/** A committed period is read-only; editing it would break every proof drawn against it. */
async function lockedPeriod(date: string): Promise<string | null> {
  const period = periodFor(date);
  if (!period) return null;
  const commit = await loadCommit(period.id);
  return commit ? period.label : null;
}

export async function GET() {
  if (!(await authorised())) return deny();
  return NextResponse.json({ transactions: await loadTransactions() });
}

export async function POST(req: Request) {
  if (!(await authorised())) return deny();
  let body: { transactions?: Partial<Transaction>[] };
  try { body = await req.json(); } catch { return NextResponse.json({ error: "bad json" }, { status: 400 }); }

  const incoming = body.transactions ?? [];
  if (!incoming.length) return NextResponse.json({ error: "no transactions" }, { status: 400 });

  const errors = incoming.flatMap((t, i) => validateTransaction(t).map((e) => `row ${i + 1}: ${e}`));
  if (errors.length) return NextResponse.json({ errors }, { status: 400 });

  for (const t of incoming) {
    const locked = await lockedPeriod(t.date as string);
    if (locked) return NextResponse.json({ error: `${locked} is committed and read-only` }, { status: 409 });
  }

  const existing = await loadTransactions();
  let counter = existing.length;
  const added = incoming.map((t) => ({ ...t, id: `n${Date.now()}${++counter}` }) as Transaction);
  await saveTransactions([...existing, ...added].sort((a, b) => a.date.localeCompare(b.date)));
  return NextResponse.json({ added: added.length });
}

export async function PATCH(req: Request) {
  if (!(await authorised())) return deny();
  let body: { transaction?: Transaction };
  try { body = await req.json(); } catch { return NextResponse.json({ error: "bad json" }, { status: 400 }); }
  const next = body.transaction;
  if (!next?.id) return NextResponse.json({ error: "missing id" }, { status: 400 });

  const errors = validateTransaction(next);
  if (errors.length) return NextResponse.json({ errors }, { status: 400 });

  const list = await loadTransactions();
  const current = list.find((t) => t.id === next.id);
  if (!current) return NextResponse.json({ error: "not found" }, { status: 404 });

  // Both the period it is leaving and the period it is joining must be open.
  for (const date of [current.date, next.date]) {
    const locked = await lockedPeriod(date);
    if (locked) return NextResponse.json({ error: `${locked} is committed and read-only` }, { status: 409 });
  }

  await saveTransactions(
    list.map((t) => (t.id === next.id ? next : t)).sort((a, b) => a.date.localeCompare(b.date)),
  );
  return NextResponse.json({ ok: true });
}

export async function DELETE(req: Request) {
  if (!(await authorised())) return deny();
  const id = new URL(req.url).searchParams.get("id");
  if (!id) return NextResponse.json({ error: "missing id" }, { status: 400 });

  const list = await loadTransactions();
  const target = list.find((t) => t.id === id);
  if (!target) return NextResponse.json({ error: "not found" }, { status: 404 });

  const locked = await lockedPeriod(target.date);
  if (locked) return NextResponse.json({ error: `${locked} is committed and read-only` }, { status: 409 });

  await saveTransactions(list.filter((t) => t.id !== id));
  return NextResponse.json({ ok: true });
}

const push = (s, text) => s.writeBin(Utils.toArray(text, "utf8"));

function commitmentScript({ periodId, root, count, supersedes }) {
  const s = new LockingScript().writeOpCode(OP.OP_FALSE).writeOpCode(OP.OP_RETURN);
  push(s, "HFLEDGER");
  push(s, "1");
  push(s, periodId);
  push(s, root);
  push(s, String(count));
  if (supersedes) push(s, supersedes);
  return s;
}
