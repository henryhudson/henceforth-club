Starting Henceforth — the /learn tutorials section

Design spec · 2026-06-13 · henceforth.club. Turns the existing /learn stub ("First episode coming soon") into a real episode gallery + per-episode pages for the Starting Henceforth video series. Strategy: teach, then convert — the free episodes earn the app's $9.99 price by showing the real machine. Spec only; the build is its own plan. Companion-validated mockups live in .superpowers/brainstorm/.

Two surfaces, two jobs. X/Twitter is the reach engine (muted-autoplay, fast-scroll feed — the episode cut is optimised there, and that work belongs to the separate episode-polish thread). henceforth.club is the premium home: full control of the chalk-on-black aesthetic, the depth X can't carry, and the conversion to a paid app. The site does not link back out to X — X sends people here; here sends them to the App Store.

Context — what exists today

  • src/app/learn/page.tsx — a stub: warm-accent hero, a "First episode coming soon" line, and a Brodie-books section (Starting FORTH / Thinking FORTH). Registered in AppSubnav under the warm (amber) accent.
  • The articles pattern is the template to mirror. src/app/articles/page.tsx is a gallery driven by a const articles = [...] array; each article is articles/<slug>/{page.tsx, content.mdx, opengraph-image.png} with an explicit openGraph/twitter metadata override and a version-tagged OG URL (?v=2) so X re-unfurls a fresh card.
  • Design system: "Phosphor Noir" — dark #06080a, Space Mono everywhere, amber #fbbf24 Henceforth accent, terminal-green #7ee787, FadeIn (Motion) scroll reveals, card-glow-warm hover borders, section-line rules.
  • Reusable assets already in the repo: src/lib/og.tsx (next/og card template), src/lib/rehype-pretty-forth.mjs + src/lib/shiki-theme.ts (Forth syntax colouring), components/MiniTerminal.tsx (a working in-browser FORTH calculator — deliberately not used here, see D2).
  • The episode source material lives in the FORTHapp repo: Tools/StartingHenceforth/episodes/*.json (storyboards, incl. the dog's speak narration) and output/<episode>.mp4 (rendered video). Episode 1 ("What is Henceforth?") is done; Episode 2 ("The Stack") is near-ready.

Decisions locked (companion-validated)

D1 — Direction: gallery index + per-episode pages

The /learn index becomes a poster-card gallery (hero → episode grid with "soon" placeholders for unmade episodes → Brodie books kept below). Each made episode gets its own page. Rejected: a single cinematic "watch" page (fewest URLs, but no per-episode shareable links and weaker SEO) and a course-syllabus index (reads empty while only 1–2 episodes are live).

D2 — Episode page: watch + code along in the real app

The page plays the episode and hands the viewer the exact commands to type into Henceforth on their own phone or Mac. No simulated terminal on the site — a toy teaches a toy; the real app holds the same machine that spends money. The MiniTerminal component is intentionally left for its Ctrl+` easter-egg role and not embedded in lessons.

Layout — sticky player + code-along rail:

SurfaceLayout
DesktopTwo columns. Left: video player that position: sticky-pins while you scroll, with Get Henceforth (App Store · Mac App Store) directly beneath. Right: the code-along rail + content blocks.
PhoneSingle stacked column — player on top, tap-to-copy commands below ("switch to Henceforth and type it").

Block order (validated selections): title/dek → hero player → Get Henceforth → Code along (the real commands, each tap-to-copy) → What you'll learn (3 concepts) → Transcript (collapsible, auto-derived) → prev/next → $9.99 App Store CTA. Dropped from the proposal: the live MiniTerminal and any on-site "watch on X" link.

D3 — Self-host the video on-site; designed poster-card thumbnails

Episode MP4s are self-hosted under public/learn/<slug>/ (no YouTube/Vimeo embed) for full control of the look and no platform chrome. The gallery thumbnail and each episode's social card are one generated asset: a designed poster card (episode number · title · motif) rendered through the existing og.tsx template — so the thumbnail is the OG share image. Rejected thumbnail styles: raw video stills (varied but off-brand-inconsistent) and a pure chalk motif (beautiful but near-identical across episodes).

D4 — Positioning: teach-then-convert, paid app ($9.99)

Henceforth is $9.99, not free (correct every CTA accordingly). The App Store CTA lands after the teaching, where the value is earned; copy is "you've seen what it does — get the machine," not "download." The $9.99 is a single universal purchase covering iPhone, iPad, and Mac.

Architecture

Routes & data

Episodes are uniform, structured data — unlike the bespoke-prose articles — so they are manifest-driven rather than per-folder MDX:

PathRole
src/lib/episodes.tsTyped Episode[] manifest — the single source of truth (see shape below).
src/app/learn/page.tsxGallery index (server component). Hero + episode grid from the manifest + Brodie books retained below.
src/app/learn/[slug]/page.tsxEpisode page (server component). generateStaticParams() over published episodes; renders the shared episode template; explicit openGraph/twitter metadata override (article pattern) so X unfurls the episode poster, not the site banner.
src/app/learn/[slug]/opengraph-image.tsxPer-episode poster card via og.tsx. Doubles as the gallery thumbnail. Version with ?v= on the metadata URL when regenerated (X cache is keyed on URL string).
public/learn/<slug>/episode.mp4Self-hosted video. Copied from FORTHapp Tools/StartingHenceforth/output/ (site cut; the X cut is a separate render owned by the episode-polish thread).

Episode manifest shape

type Episode = {
  number: number;            // 1..10
  slug: string;              // "what-is-henceforth", "the-stack"
  title: string;             // "The Stack"
  dek: string;               // one-line summary under the title
  published: boolean;        // false → renders as a "soon" tile, no page
  durationSec?: number;      // 25
  music?: { season: string; piece: string };   // "Summer", "Vivaldi · Presto (RV 315 iii)"
  concepts?: string[];       // "What you'll learn" bullets
  codeAlong?: string[];      // ["3 4 + .", "2 4 6 8 . . . .", "10 20 30 . . . ."]
  transcript?: string[];     // dog's speak lines, lifted from the FORTHapp episode JSON
  video?: { mp4: string; poster: string };
};

Transcript derivation is nearly free: the dog's narration already exists as the speak steps in the FORTHapp episode JSON. An authoring step (small Node script in scripts/, or a one-time copy) extracts steps[].text where type==="speak" into transcript. No transcription work; good for accessibility + SEO.

Components (all under src/components/learn/)

ComponentResponsibility
EpisodeCardGallery tile: poster thumbnail, episode number, title, music label; "soon" variant for unpublished. card-glow-warm hover.
EpisodePlayer (client)HTML5 <video> with poster, minimal chalk-on-black controls, no autoplay. position: sticky on desktop. Respects prefers-reduced-motion.
CodeAlong (client)Ordered command rows; each tap-to-copy via navigator.clipboard with a copied-state tick. Forth colouring reuses the rehype-pretty-forth / shiki-theme token vocabulary (operators amber, numbers green, comments grey) for visual consistency with /docs.
GetHenceforthApp Store + Mac App Store buttons, "$9.99 · one universal purchase · iPhone · iPad · Mac". Store badges only — no deep-link.
TranscriptCollapsible (<details>) list of the dog's lines.

Acceptance criteria

  1. /learn renders a gallery: hero, an episode grid (Ep 1 made; Ep 2+ as "soon" tiles), Brodie books retained below. No "coming soon" placeholder copy remains.
  2. /learn/what-is-henceforth (Ep 1) renders the episode page: sticky player (desktop), Get Henceforth, a code-along rail whose rows copy to clipboard, What-you'll-learn, a collapsible transcript, prev/next, and the $9.99 CTA.
  3. The episode MP4 plays from public/learn/<slug>/ with the poster card as its frame-zero.
  4. Unfurling an episode URL on X shows that episode's poster card (not the site banner) — explicit per-page openGraph/twitter metadata, versioned image URL.
  5. The gallery thumbnail and the OG card are the same generated asset.
  6. Mobile: the page stacks; player on top, tap-to-copy commands legible and copyable.
  7. No simulated terminal and no outbound X link appear anywhere in the section.
  8. npm run build is clean; the new routes appear in the sitemap; Lighthouse a11y has alt text on posters and a labelled video.

Non-goals (out of scope for this spec)

  • The X-optimised video cut (aspect ratio, silent-legibility, length) and any Episode-2 editorial polish — those belong to the separate episode-polish thread.
  • YouTube/Vimeo hosting; an in-page interactive terminal; an on-site "discuss on X" link.
  • Per-episode comment threads, progress tracking, or auth.
  • Auto-syncing the manifest from the FORTHapp repo at build time (v1 is a manual author/copy step; automate later if it earns it).

Resolved Henry · 2026-06-13

  1. App SKU: one price — a single universal purchase ($9.99) covers iPhone, iPad, and Mac.
  2. First deploy: Episode 1 only. Episode 2 isn't finished — it renders as a "soon" tile until its polish thread lands.
  3. Deep-link: no. Store badges only; no henceforth:// launch button.
  4. Captions: none. The dog narrates on-screen, so a WebVTT track is redundant. The collapsible on-page transcript still ships (skim + SEO).
