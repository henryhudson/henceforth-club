Provenance — high-end editorial redesign

Design spec · 2026-06-17 · henceforth.club. Supersedes the earlier "faithful + polished" spec (2026-06-17-provenance-page-design.html) — that direction was rejected as not high-end enough. New brief: a genuinely premium, editorial & photographic site for Provenance Partners. Same unlisted home (henceforth.club/provenance), same content, a far higher bar. Direction validated by mockup with Henry ("much better"; editorial confirmed, refinements pending).

The honest truth about this design: ~70% of it is photography. An editorial look lives or dies on image quality. AI generation is unavailable in this environment and free stock is only stock-grade, so the build uses sourced CC photography as scaffolding and is architected to swap in Provenance's own (or premium-licensed) photography before go-live. The CSS/type system is the high-end part we can finish now; the imagery is the dependency that makes it land.

Decisions locked (with Henry)

  • Aesthetic: editorial & photographic — big imagery, refined serif display + clean sans, large type scale, generous whitespace, calm and confident. Reference register: Natoora / a premium food magazine. Restraint = premium.
  • Purple is an accent, not a field (hard-won): white/near-white background, near-black charcoal text, green the accent, purple only a whisper (logo + at most one small detail). No purple headings, bands, or footer.
  • Scope unchanged: unlisted route at henceforth.club/provenance (not in nav/sitemap, noindex); standalone (henceforth.club chrome suppressed); its own header + footer; real Provenance content; mailto: contact. Goes live on main only on Henry's approval.
  • Imagery: sourced CC stock stand-ins now (already downloaded), swap real/premium photography before go-live. Layout built to absorb real images by simply replacing files.

Typography no mono

Fraunces (variable optical serif) for editorial display headlines — including weight/italic contrast for the signature moments — paired with a clean humanist sans (DM Sans or Inter) for body/labels, loaded via next/font/google. Large editorial scale; generous line-height and whitespace.

Photography build-time refine

Cohesive, bright, natural-light produce imagery. v1 uses the sourced CC set (Romanesco macro, hands-with-produce, green beans, field rows); these are stand-ins. Refinements to finalize against live screenshots: the hero must be a balanced editorial composition (not a single oversized vegetable), consistent grade across shots, and ultimately Provenance's real photography.

Page structure (editorial)

  1. Header — logo, section nav, green Contact button.
  2. Hero — large produce photograph + a restrained Fraunces headline ("Globally sourced exotic vegetables." / strapline) + one green CTA. Balanced composition, generous air.
  3. Story / About — editorial two-column: photo + the founding narrative (2011, Vegpro Kenya, global network, year-round premium & prepared produce) + elegant stats.
  4. Values & expertise — all 8, set editorially (typographic list or restrained cards, not gimmicky).
  5. Products — the full range as an elegant typographic index, with a produce photo used editorially.
  6. Accreditations — the real certification logos, quietly presented.
  7. Suppliers — the global-network story.
  8. Contact — address, mailto:hello@provenance.co.uk (green CTA), Modern Slavery PDF.

Acceptance criteria

  1. Reads as premium editorial: Fraunces display type, big imagery, generous whitespace; green accent only; purple only a whisper; charcoal (not purple) headings and footer.
  2. All real content present (all 8 values, full product range, accreditations, suppliers, contact). mailto: works.
  3. Unlisted invariant intact: not in nav/sitemap, noindex; chrome suppressed; homepage unaffected.
  4. Photography is file-swappable: replacing files in public/provenance/editorial/ updates the site with no layout change.
  5. npm run test green; npm run build clean, /provenance prerenders; visually verified on a screenshot/preview (hero balanced, no green-block placeholders, no oversized-vegetable hero).
